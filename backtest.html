How to read this

Use the chart and table together:
Return vs drawdown
Two portfolios can have similar returns but very different drawdowns. Drawdown reflects peak-to-trough declines.
Volatility
Volatility summarizes typical day-to-day movement. It is descriptive, not a prediction.
CAGR
CAGR is the constant annual growth rate that would produce the same total return over the period.
