API

1) Endpoint example GET /api/aggregate?wallets=GABC,GDEF
2) Query parameter wallets: comma-separated Stellar public addresses
3) Example API request 
curl "https://YOUR-DOMAIN/api/aggregate?wallets=GABC,GDEF"
4) Example JSON response 
{
  "walletCount": 2,
  "totalXLM": 1234.56,
  "totalUSD": 145.67,
  "assets": [
    {
      "symbol": "XLM",
      "amount": 1234.56,
      "usdValue": 145.67,
      "allocationPercent": 100
    }
  ]
}
5) Features
  • Lightweight public GET endpoint
  • No database, no authentication
  • Skips invalid wallets gracefully
  • CoinGecko XLM/USD pricing + Horizon account aggregation
  • Deterministic JSON structure for integrations
